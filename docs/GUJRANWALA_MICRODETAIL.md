# Gujranwala eye-level craft microdetail v1

This pass develops **close-range craftsmanship** in the existing playable Gujranwala Home territory.

The first beauty pass improved immediate courtyard composition. The second depth/patina pass improved the
perimeter and skyline. This pass works at the player's walking-camera distance: the small material decisions
that keep pale plaster and repeated bays from reading as generic modular architecture.

## Added

- eight restrained upper-border accents;
- sixteen dark timber reveal strips around the existing bay rhythm;
- eight lower plinth accents;
- ten selective plaster-repair fields;
- six sparse wall rings;
- two high hanging cords with tiny tick-driven motion;
- two quiet storage corners with small vessel groups, rolled mats and folded cloth.

## Art-direction rule

The scene should reward three viewing distances:

```text
far     → skyline / foliage / wall rhythm
medium  → garden pockets / jali depth / textiles / practical light
near    → reveals / trim / repairs / wall hardware / stored household objects
```

The close layer must remain subordinate to the whole composition. Not every surface receives ornament.

## Selective rather than procedural

The repair fields are intentionally unequal. Wall rings do not appear on every bay. Only two rings carry
a hanging cord. Storage occurs in two corners rather than becoming a repeated prop kit.

This is the same preservation principle used by the world-memory-anchor work:

> industrial generation may replace the asset family, but it should not erase the authored irregularity.

## F7 ownership

The pass belongs to the existing reversible authored-courtyard presentation:

- authored-refinement off → microdetail disappears;
- authored-refinement on → microdetail returns;
- the pass uses the existing chapter tick for the two small cord motions;
- there is no second timer or shader TIME.

## Historical boundary

These details are **source-informed visual grammar**, not a measured 1792 Gujranwala inventory.

The corpus supports dark timber/plaster contrast, repair layers, household storage, sparse wall hardware and
edge occupation. It does not authenticate these exact rings, trim colors, repair locations, vessels or storage
arrangements.

Final historical art review still requires period-nearer evidence.
