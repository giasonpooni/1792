## Predeclared trial

One interactive coding/vision assistant session is the author. The same session
views real retained renders and produces a bounded complete source replacement.
The deterministic runner in NET is only a transport/measurement relay; it neither
invents a defect nor synthesizes a known correction. This is not a separately
hosted autonomous model API benchmark, provider-signed authorship, blinded art
review or an independent test-author/model experiment.

Goal: improve the readability of the small smith workplace at the existing
inspection camera: visible bench joinery, forge construction and layered coals,
while preserving all original mechanical conditions and the 160-draw-call gate.
The technical policy and 640x360 daylight/evening camera/tick remain unchanged.
The first source response is frozen before the native trial. At most two genuine
source revisions are planned; the next revision may be authored only after
inspecting the first native result. No LLM source is written back to live Home.

Baseline evidence: NET workflow36555220875, artifact11027207297 (archive SHA256
bba9b817343d681637665b7a301452be735d9c8cf3e1150207e7c1e5517ca008).
The actual viewed daylight/evening PNG digests are retained in c01/decision.json.
These references declare observed inputs; they do not attest to a provider's
internal perception. Original preview images are retained in the evidence
archive, not copied into source.

joinery/forge curb/cloth edge details, dark coals and small emissive embers. The

The expected draw cost is a hypothesis until the native workcell records it.
The source contains original connective-fiction art, not a surveyed forge or an
assertion of historically authentic tools/dress.
